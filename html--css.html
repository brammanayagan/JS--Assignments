Top 16 JavaScript Basics

1. What is JavaScript?

JavaScript is a high-level programming language used to build interactive web applications. It runs in the browser and also on servers using Node.js. It is dynamically typed and event-driven. Today it is used for frontend, backend, and full-stack development.

2. Variables

Variables are used to store data values in memory. They act as named containers for storing information. JavaScript allows dynamic typing. Values stored inside variables can change during execution.

3. var, let, const

These are used to declare variables in JavaScript. var has function scope and allows redeclaration. let and const have block scope and prevent redeclaration. const cannot be reassigned after initialization.

4. Data Types

Data types define the type of value stored in a variable. JavaScript supports primitive and non-primitive types. It is dynamically typed, so types are decided at runtime. Understanding data types prevents logical errors.

5. Primitive Data Types

Primitive types include string, number, boolean, null, undefined, bigint, and symbol. They are immutable in nature. They are stored directly in stack memory. Assigning them copies the value.

6. Non-Primitive Data Types

Objects, arrays, and functions are non-primitive types. They are also called reference types. They are stored in heap memory. Assigning them copies the reference, not the actual value.

7. Operators

Operators are symbols used to perform operations on values. Examples include arithmetic, comparison, logical, and assignment operators. They help in calculations and decision making. Strict equality (===) is recommended over loose equality (==).

8. Conditional Statements

Conditional statements control decision making in programs. if, else, and switch are common conditional structures. They execute code blocks based on conditions. They help control program flow.

9. Loops

Loops are used to repeat a block of code multiple times. Common loops include for, while, and do-while. They are useful for iterating over arrays. Proper loop control prevents infinite loops.

10. Functions

Functions are reusable blocks of code. They help in organizing and modularizing programs. JavaScript supports function declarations and expressions. Functions can accept parameters and return values.

11. Arrow Functions

Arrow functions provide shorter syntax for writing functions. They do not have their own 'this' keyword. They are commonly used in modern JavaScript. They are widely used in React and callbacks.

12. Arrays

Arrays store multiple values in a single variable. Elements are accessed using index numbers. They support built-in methods like map and forEach. Arrays are widely used in data handling.

13. Objects

Objects store data in key-value pairs. They are used to represent real-world entities. Properties can be accessed using dot or bracket notation. Objects are core to backend and API data structures.

14. Hoisting

Hoisting moves variable and function declarations to the top of their scope. var is initialized as undefined during hoisting. let and const stay in the temporal dead zone. Understanding hoisting prevents unexpected behavior.

15. Scope

Scope determines where variables can be accessed. JavaScript has global, function, and block scope. Lexical scope is decided at declaration time. Proper scope management prevents conflicts.
